# Introduction
Coral Xchange is a stock exchange simulator. Our goal is to create a free platform with staple "paper trading" features in order for people to learn how to trade. Users will have a set starting balance to use to buy and sell stocks that are updated with real time flutcuation. Newer traders can practice the basics of trading, getting used to features of normal trading, like setting stop orders or basic understanding of how the market works, without any of the risks. More experienced traders can also benefit by testing strategies before appyling them to the real market. Join the school today!🐟

## Running front-end:

Ensure angular is installed with `ng --version`, if not installed use `npm install -g angular/cli`

Once installed run `ng serve`


## Running back-end:

Load an API key for stockdata.org in a .env file under the name STOCK_API_KEY.

Run `go run server.go` in the backend-dev directory.

Test backend with `go test -v`.
